## I01 / I02 evidence notes

- I01 commit `499b632` and `mobile/src/ui/__tests__/CatalogScreen.test.tsx` provide component-level evidence for catalog states, selection/prepare/play routing, now-playing text, player error messaging, unavailable-player behavior and the RN shell's accessibility labels. `cd mobile && npm run verify` is green with 33 tests.
- D03 commit `8c6b19b` provides RN host/module lifecycle and deterministic native-input instrumentation evidence. The 5/5 API-35 result does not prove live media playback, audible track changes or physical sensors.
- I02 release security evidence is the processed release manifest: `mobile/android/app/build/intermediates/merged_manifest/release/processReleaseMainManifest/AndroidManifest.xml` resolves `android:usesCleartextTraffic="false"`. Debug resolves it to `true` solely for the Metro connection.
- Still pending: physical M00 flow, volume/shake response, live/audible playback, deterministic fixture playback while emulator-to-host `10.0.2.2:8099` is blocked by `SocketException: EPERM`, real-device performance measurements, CI execution and signed release/upgrade/rollout evidence.
